# Monitoring dan Billing API MikroTik

Sistem monitoring jaringan dan manajemen billing pelanggan internet berbasis API MikroTik menggunakan CodeIgniter 4.

---

## Tentang Project

Aplikasi ini dibuat untuk membantu pengelolaan layanan internet pada ISP/Wifi RT RW Net dengan fitur monitoring jaringan dan sistem billing pelanggan secara terintegrasi menggunakan API MikroTik.

Sistem menyediakan:
- Monitoring trafik jaringan
- Monitoring status router
- Manajemen pelanggan internet
- Pengelolaan pembayaran
- Pengelolaan paket layanan
- Laporan pembayaran
- Pengelolaan perbaikan jaringan
- Dashboard monitoring realtime

---

# Teknologi Yang Digunakan

- PHP 8.2+
- CodeIgniter 4
- MySQL / MariaDB
- jQuery
- Chart.js
- MikroTik API

---

# Persyaratan Sistem

Pastikan server sudah memiliki:

- PHP 8.2 atau lebih baru
- Composer
- MySQL / MariaDB
- Git

Extension PHP yang diperlukan:

- intl
